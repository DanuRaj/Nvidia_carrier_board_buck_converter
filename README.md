# Nvidia_carrier_board_buck_converter

<img width="500" height="500" alt="{3F92B3EE-17E5-41CC-94A1-E57578842CAD}" src="https://github.com/user-attachments/assets/3bc8839b-9764-46d1-9860-162c8799513f" />

Nvidia_carrier_board_buck_converter: A redundant 16V, 10A power supply designed for drone applications. This system ensures continuous and reliable power to critical components, 
preventing a loss of control in case of a single power source failure.

## Board Function Description
- Controller Interface: This system is designed to provide a reliable and uninterrupted power supply by combining two independent buck converter outputs through
  ideal diode OR-ing controllers. The configuration ensures that if one power source fails, the other seamlessly takes over without significant voltage drop or back-feeding.
- Protection Features: Overcurrent and Short circuit, Thermal shutdown (168C), Output reverse current protections.
- Device Specification: Input voltage 6-36V, Output voltage 16V(10A max).
